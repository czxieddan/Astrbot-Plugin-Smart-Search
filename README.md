# AstrBot 智能联网搜索插件

为 AstrBot 的 LLM 提供实时联网搜索能力，基于 Tavily API。

**作者**: Yezi  
**版本**: 1.3.0

## 功能特点

- 🔍 **智能搜索** - LLM 自动判断何时需要联网搜索
- ⏱️ **时效过滤** - 可配置只搜索指定天数内的内容
- 🔑 **多 Key 轮换** - 支持最多 3 个 API Key，额度用尽自动切换
- 📎 **来源显示** - 可选在回复末尾显示参考来源

## 安装

1. 将插件文件夹放入 AstrBot 的 `addons/plugins/` 目录
2. 重启 AstrBot

## 配置

在 AstrBot 管理面板中配置以下选项：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `tavily_api_key_1` | Tavily API Key（主要） | 必填 |
| `tavily_api_key_2` | 备用 API Key（可选） | - |
| `tavily_api_key_3` | 备用 API Key（可选） | - |
| `max_days_old` | 内容时效限制（天），0 表示不限制 | 0 |
| `show_sources` | 是否显示搜索来源 URL | false |

### 获取 Tavily API Key

1. 访问 [https://tavily.com](https://tavily.com)
2. 注册账号并登录
3. 在控制台获取 API Key
4. 免费额度：每月 1000 次搜索

## ⚠️ 重要提示

**使用本插件前，必须关闭以下功能：**

1. **关闭 AstrBot 自带的联网搜索**
   - 进入 AstrBot 管理面板
   - 找到「大语言模型」或「LLM 设置」
   - 关闭「联网搜索」或「Web Search」选项

2. **关闭其他搜索插件**
   - 如果安装了其他联网搜索插件，请先禁用或卸载
   - 避免多个搜索插件冲突

## 使用方式

配置完成后，直接与 LLM 对话即可。当 LLM 判断需要联网获取信息时，会自动调用搜索功能。

**示例对话：**
- "今天有什么新闻？"
- "hoi4 最新版本是什么？"
- "最近有什么好看的电影？"

## 常见问题

**Q: 搜索结果不够新？**  
A: 配置 `max_days_old` 参数，例如设为 7 只搜索一周内的内容。

**Q: API 额度用完了？**  
A: 配置多个 API Key，插件会自动轮换使用。

**Q: 搜索没有触发？**  
A: 确保已关闭 AstrBot 自带的联网搜索功能。
